# Mainline Linux research

The maintained build in this repository is Droidian using the Samsung/LineageOS
4.19 kernel and Android vendor HALs. Mainline Linux and postmarketOS are separate
porting efforts.

The inherited research points to
[itzreesa/sm8250-mainline](https://github.com/itzreesa/sm8250-mainline), branch
`6.13.0-gts7l`. Panel initialization, Wi-Fi, audio, S-Pen, power management and
charging would each need source review and T870 testing before describing a
usable mainline port. Previous estimates and desktop capability claims have
been removed because this project has no corresponding T870 measurements.
