# Galaxy Tab S7 Wi-Fi (SM-T870) — flash guide

Use the T870 flash bundle and the T870 rootfs artifact from the **same build**.
The rootfs already includes the adaptation and camera packages. First boot and
hardware functionality still need T870 testing.

Flashing userdata erases the tablet's data. Start with an unlocked bootloader,
a working T870 TWRP recovery, a USB cable, and a Linux PC with `heimdall`, `adb`
and `simg2img`. Bootloader unlocking erases data and permanently changes Knox
state. Keep the stock firmware and a backup available for recovery.

1. Unpack the rootfs ZIP into `rootfs/` and place `boot.img`, `dtbo.img` and
   `vbmeta-disabled.img` from the flash bundle in the working directory.
2. Enter Download Mode: power off, hold both volume buttons and connect USB.
3. Install TWRP for **gts7lwifi**, then boot directly into it:

```sh
heimdall flash --VBMETA vbmeta-disabled.img --RECOVERY twrp-gts7lwifi.img --no-reboot
```

4. Convert the generated LVM userdata image and stream it through TWRP:

```sh
simg2img rootfs/data/userdata.img userdata.raw.img
cat userdata.raw.img | adb shell -T 'dd of=/dev/block/by-name/userdata bs=4M'
```

5. Return to Download Mode and flash the verified boot images:

```sh
adb reboot download
heimdall flash --VBMETA vbmeta-disabled.img --BOOT boot.img --DTBO dtbo.img --no-reboot
```

6. Exit Download Mode with Volume Down + Power and release the keys to boot.

Preserve `super`/`vendor`: this Halium build uses the Android vendor HALs.
The raw `userdata` image must use the LVM layout generated by this project.
A generic recovery-installable rootfs ZIP has a different format.
The template's generic `flash_all.sh` assumes fastboot; this Samsung device
uses Heimdall Download Mode and the commands above.

For initramfs debugging, replace `boot.img` with `boot-rescue.img` in the last
Heimdall command. The inherited rescue setup uses USB networking and telnet at
`192.168.2.15:23`. Collect boot logs before changing device configuration.
